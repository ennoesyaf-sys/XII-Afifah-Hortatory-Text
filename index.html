3. Desain infografis

Susun tata letaknya mengikuti struktur teks:

ATAS: Judul + Thesis
Argument 1: ikon + bukti
Argument 2: ikon + bukti
Argument 3: ikon + bukti
BAWAH: Recommendation (We should …)

Tips dari contoh infografis di buku (Step Up 3 hlm. 100-101)

  • Satu ide per kotak, teks pendek (sekitar 25 kata per kotak).
  • Pakai angka, ikon, dan warna kontras supaya mudah dibaca dari jauh.
  • Judul besar, isi lebih kecil, urutan baca jelas dari atas ke bawah.
  • Tulis sumber data kalau memakai angka atau fakta.
  • Tidak ada PR, jadi targetkan selesai di kelas: buat sederhana dan bagi tugas (judul, tiap argumen, recommendation).
Persiapan presentasi

4. Kerangka presentasi 3 menit

Bagi peran: pembuka dan thesis, argument 1, argument 2, argument 3 dan recommendation, penutup.

Pembuka: Good morning, everyone. Our topic is … Our thesis is that teenagers can …

Argumen: Firstly, … For example, … Moreover, … In addition, …

Recommendation: Therefore, we should … / Every teenager must …

Penutup: In conclusion, … Thank you for listening.

  • Bicara menghadap kelas, bukan membaca infografis.
  • Gunakan minimal 3 modal verbs dan 3 connectives saat berbicara.
  • Kalau ada waktu, latihan satu kali dengan timer 3 menit.
